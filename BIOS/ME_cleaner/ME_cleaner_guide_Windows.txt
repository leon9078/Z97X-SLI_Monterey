ME_cleaner BIOS mod guide

WARNING: macOS heavily rely on Intel Management Engine. If ME is cleared, then macOS will have the following issues:
- Booting will be slower, with a message saying "DRMStatus: iTunes/Apple Store Content Access Problem. Content playback may be disabled on this computer. You can continue to use the machine, but you should contact an Apple support representative. ErrorCode: 8877652"
  - Noted when booting in verbose mode ("-v" boot-arg or Cmd+V at boot)
- DRM will be broken, which is a requirement in macOS such as playing DRM media
- It takes a bit more than 2 minutes to wake from sleep (S3) or hibernation (S4)
- maybe other issues...

So, IF you want to use macOS than FORGET this guide and just use BIOS/Z97XSLI.fd



Complete list of modifications:
1) Update "MERecoveryDxe" module by changing Depex expression from TRUE to FALSE
2) Use "me_cleaner" python tool with "-S" switch (code removal + HAP/AltMeDisable bit)

Prerequisites:
- Windows 10 version 1703 or higher
- internet connection
- already followed BIOS/BIOS_mod_guide_Windows.txt
- modded BIOS/Z97XSLI.fd

We will work entirely in the Documents\ME_cleaner folder

We need this files/softwares:
1) MMTool 5.02.0024 Mod (https://www.mediafire.com/file/t5w592roapx6wzl/MMTool_Aptio_5.02.0024_Mod.7z/file)
2) me_cleaner from master branch (https://github.com/corna/me_cleaner)
3) UEFITool NE, latest release for Windows [x64] (https://github.com/LongSoft/UEFITool/releases/latest)





Open Command Prompt from the taskbar
> cd Documents
> cls
> mkdir ME_cleaner
> cd ME_cleaner

Open Mullvad Browser from the taskbar
Download "MMTool 5.02.0024 Mod": https://www.mediafire.com/file/t5w592roapx6wzl/MMTool_Aptio_5.02.0024_Mod.7z/file

Back to CMD
> copy "..\MMTool Aptio 5.02.0024 Mod.7z" .
> set PATH=%PATH%;C:\Program Files\7-Zip\
> 7z x "MMTool Aptio 5.02.0024 Mod.7z"



We want to update "MERecoveryDxe" module by changing Depex expression from TRUE to FALSE, otherwise Intel ME is not really neutralized after using "me_cleaner" tool (It should be a GIGABYTE only thing)

Grab your copy of the modded BIOS (Z97XSLI.fd), either:
- locally
> copy ..\Z97XSLI.fd .

- remotely:
> curl -O https://raw.githubusercontent.com/leon9078/Z97X-SLI_Monterey/refs/heads/master/BIOS/Z97XSLI.fd



> curl -LO https://github.com/LongSoft/UEFITool/releases/download/A74/UEFITool_NE_A74_win64.zip
> tar -xf UEFITool_NE_A74_win64.zip
> explorer .

Open UEFITool.exe
File > Open image file... > "Z97XSLI.fd" > Open
Action > Search... > Text > "MERecoveryDxe", "Unicode": check > OK

There will be 1 result inside MERecoveryDxe/.../UI section
Double click on it, it will select "UI section"

Click on "MERecoveryDxe" and check this important infos on the right:
- File GUID: F1FCD66F-8966-441E-909C-77F211AB9C3E
- Attributes: 40h
- Data checksum: 78h, valid

Now click on DXE dependency section and check this important infos on the right:
- Offset: 18h
- Header size: 4h (4)
- Parsed expression:
  TRUE
  END

Quit UEFITool

Back to CMD
> start /b /min /wait MMTool Z97XSLI.fd /ec F1FCD66F-8966-441E-909C-77F211AB9C3E MERecoveryDxe.ffs

Back to File Explorer
Drag "MERecoveryDxe.ffs" into Hextor icon while holding Shift

We need to go to the beginning of DXE dependency section body.
Offset + Header size. 0x18 + 0x04 = 0x1C

Search > Go To address... > 0x1C > OK

As per UEFI PI spec (https://uefi.org/specs/PI/1.9/V1_PEI_Foundation.html#dependency-expression-opcode-summary), 0x06 value means TRUE, we want to change this to FALSE, 0x07

Type "07"

Now we must update the Data checksum, we've added +0x01, we need to remove 0x01 from that value

Search > Go To address... > 0x11 > OK
Edit > Select Range... > Range end: +1
Operations > Modify with expression: x-1
File > Save as... > "C:\Users\Leonardo\Documents\ME_cleaner\MERecoveryDxe_mod.ffs" > Save
File > Exit

Back to CMD
> start /b /min /wait MMTool Z97XSLI.fd /r F1FCD66F-8966-441E-909C-77F211AB9C3E MERecoveryDxe_mod.ffs





Now we want to actually neutralize Intel ME with "me_cleaner" tool!!!

> curl -JO https://codeload.github.com/corna/me_cleaner/zip/refs/heads/master
> tar -xf me_cleaner-master.zip
> move Z97XSLI.fd me_cleaner-master\
> start cmd /k cd me_cleaner-master\
> python me_cleaner.py -S -O Z97XSLI_no_ME.fd Z97XSLI.fd
> move Z97XSLI_no_ME.fd ..
> exit
> rmdir /s /q me_cleaner-master
> del me_cleaner-master.zip MERecoveryDxe_mod.ffs MERecoveryDxe.ffs





We have finished neutralizing Intel ME! Now, we want to create the report

Back to File Explorer
Open UEFITool.exe
File > Unload GUID database
File > Open image file... > "Z97XSLI_no_ME.fd" > Open
File > Generate report... > [default name is fine] > Save
File > Quit

Back to CMD
> reg delete HKCU\SOFTWARE\CodeRush /f
> reg delete HKCU\SOFTWARE\QtProject /f

Back to File Explorer
Open MMTool.exe
Load Image > [select Libraries > Documents folder > ME_cleaner folder] > "Z97XSLI_no_ME.fd" > Open
Create Report > OK
Close

Back to CMD
> attrib -r MMTool.exe
> del MMTool.exe "MMTool Aptio 5.02.0024 Mod.7z" UEFITool.exe UEFITool_NE_A74_win64.zip
> exit

We now have 3 files:
1) Z97XSLI_no_ME.fd (edited BIOS file)
2) Z97XSLI_no_ME.fd.report.txt (UEFITool report)
3) Z97XSLI_no_ME.rpt (MMTool report)



Done!!!!!!!
