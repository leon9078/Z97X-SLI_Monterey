ME_cleaner BIOS mod guide

WARNING: macOS heavily rely on Intel Management Engine. If ME is cleared, then macOS will have the following issues:
- Booting will be slower, with a message saying "DRMStatus: iTunes/Apple Store Content Access Problem. Content playback may be disabled on this computer. You can continue to use the machine, but you should contact an Apple support representative. ErrorCode: 8877652"
  - Noted when booting in verbose mode ("-v" boot-arg or Cmd+V at boot)
- DRM will be broken, which is a requirement in macOS such as playing DRM media
- It takes a bit more than 2 minutes to wake from sleep (S3) or hibernation (S4)
- maybe other issues...

So, IF you want to use macOS than FORGET this guide and just use BIOS/Z97XSLI.fd



Complete list of modifications:
1) Delete MERecoveryDxe ffs using MMTool
2) Use "me_cleaner" python tool with "-S" switch (code removal + HAP/AltMeDisable bit)

Prerequisites:
- Windows 10 version 1607 or higher
- Internet connection
- Already followed BIOS/BIOS_mod_guide_Windows.txt
- modded BIOS/Z97XSLI.fd

We will work entirely in the Documents\ME_cleaner folder

We need this files/softwares:
1) UEFITool NE latest for Windows [x64] (https://github.com/LongSoft/UEFITool/releases/latest)
2) MMTool 5.02.0024 Mod (https://www.mediafire.com/file/t5w592roapx6wzl/MMTool_Aptio_5.02.0024_Mod.7z/file)
3) me_cleaner from master branch (https://github.com/corna/me_cleaner)





Open Command Prompt, then:
> cd Documents
> mkdir ME_cleaner
> cd ME_cleaner
> curl -LO https://github.com/LongSoft/UEFITool/releases/download/A73/UEFITool_NE_A73_win64.zip
> tar -xf UEFITool_NE_A73_win64.zip

Open Mullvad Browser and download MMTool 5.02.0024 Mod (https://www.mediafire.com/file/t5w592roapx6wzl/MMTool_Aptio_5.02.0024_Mod.7z/file)

Back to CMD
> copy "..\MMTool Aptio 5.02.0024 Mod.7z" .
> set PATH=%PATH%;C:\Program Files\7-Zip\
> 7z x "MMTool Aptio 5.02.0024 Mod.7z"



We want to delete "MERecoveryDxe" module, otherwise Intel ME is not really neutralized after using "me_cleaner" tool. It should be a GIGABYTE only thing.

Grab your copy of the modded BIOS (Z97XSLI.fd), either locally or through:
> curl -LO https://github.com/leon9078/Z97X-SLI_Monterey/raw/refs/heads/master/BIOS/Z97XSLI.fd
> explorer .

Open MMTool.exe
     Load Image > "Z97XSLI.fd" > Open
         Delete > Volume Index: 02:01-00, File Index: 5C, Source size: 0000470D > Delete
Save Image as.. > "tmp" > Save
Close



Now we want to actually neutralize Intel ME with "me_cleaner" tool!!!

Back to CMD
> del Z97XSLI.fd
> curl -LJO https://github.com/corna/me_cleaner/archive/refs/heads/master.zip
> tar -xf me_cleaner-master.zip
> move tmp.fd me_cleaner-master\
> cd me_cleaner-master
> python me_cleaner.py -S -O Z97XSLI_no_ME.fd tmp.fd
> move Z97XSLI_no_ME.fd ..
> cd ..
> rmdir /s /q me_cleaner-master
> del me_cleaner-master.zip





We have finished neutralizing Intel ME! Now, we want to create the report

Back to File Explorer
Open UEFITool.exe
File > Unload GUID database
File > Open image file... > "Z97XSLI_no_ME.fd" > Open
File > Generate report... > [default name is fine] > Save
File > Quit

Open MMTool.exe
Load Image > "Z97XSLI_no_ME.fd" > Open
Create Report > OK
Close

Back to CMD
> reg delete HKCU\SOFTWARE\CodeRush /f
> reg delete HKCU\SOFTWARE\QtProject /f
> attrib -r MMTool.exe
> del MMTool.exe "MMTool Aptio 5.02.0024 Mod.7z" UEFITool.exe UEFITool_NE_A73_win64.zip
> exit

We now have 3 files:
1) Z97XSLI_no_ME.fd (edited BIOS file)
2) Z97XSLI_no_ME.fd.report.txt (UEFITool report)
3) Z97XSLI_no_ME.rpt (MMTool report)



Done!!!!!!!
